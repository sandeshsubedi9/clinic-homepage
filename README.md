# Clinic Homepage 🏥

A premium, responsive medical clinic landing page built with **Next.js**, **React**, **Framer Motion**, and **Tailwind CSS** — featuring a confidential healthcare showcase, interactive service sections, and a modern UI designed for patient trust.

---

  (ctrl + click to open it in new tab)
  
🔗 **https://clinic-homepage-nu.vercel.app/**

---

## 🚀 Features

- **Confidential Healthcare Focus** — Designed specifically for sexual health clinics with a focus on privacy and judgment-free care.
- **Interactive Hero Section** — Features an automated image carousel and smooth entry animations powered by Framer Motion.
- **Comprehensive Services** — Clearly organized sections for STD testing, treatment, and medical consultations.
- **Stats & Achievements** — Highlights clinic impact with an interactive statistics section.
- **Responsive & Modern UI** — Fully mobile-friendly layout built with Tailwind CSS for a seamless experience across all devices.
- **Dynamic Animations** — Scroll-triggered animations and hover effects that enhance user engagement.
- **Quick Appointments** — Prominent Call-to-Action (CTA) buttons for easy appointment booking.

---

## 🛠️ Tech Stack

- **Frontend:** Next.js, React, TypeScript, Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Development Tools:** ESLint, PostCSS
